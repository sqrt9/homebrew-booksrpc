# Sqrt9 Booksrpc

## How do I install these formulae?

`brew install sqrt9/booksrpc/<formula>`

Or `brew tap sqrt9/booksrpc` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "sqrt9/booksrpc"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
